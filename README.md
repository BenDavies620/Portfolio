# Benjamin Davies | Developer Portfolio

My personal developer portfolio, built during the Netmatters Scion Coalition Scheme to showcase my projects, technical skills and development progress.

## Features

- Responsive layout for desktop, tablet and mobile
- Project gallery showcasing my development work
- About Me page highlighting my background and skills
- Coding examples and information about the Scion Coalition Scheme
- Contact form with server-side validation
- Database integration for storing enquiries
- SMTP email handling for contact form submissions

## Technologies

- HTML
- CSS and Sass
- JavaScript
- PHP
- MySQL
- PDO
- Composer and PHP dotenv
- Git and GitHub

## What I Learnt

Building this portfolio helped me develop my front-end skills while gaining practical experience with PHP, database integration and server-side form handling. I also learnt how to validate user input, manage environment variables, send emails through SMTP and deploy a PHP application to a live server.

## Running Locally

1. Clone or download this repository.
2. Set up a local PHP development environment, such as XAMPP.
3. Install the project dependencies using Composer.
4. Create a local `.env` file containing the required database credentials.
5. Configure the local database and import any required tables.
6. Run the project through your local development server.

Keep environment files and database credentials private. Do not commit them to GitHub.
