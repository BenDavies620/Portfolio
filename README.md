# Benjamin Davies | Developer Portfolio

My personal portfolio, built during the Netmatters Scion Coalition Scheme to showcase my development projects, technical skills and progress.

## Features

- Responsive layout for desktop, tablet and mobile
- Project gallery showcasing my work
- About Me page with my background and skills
- Coding examples
- Information about the Scion Coalition Scheme
- Contact section

## Technologies

- HTML
- CSS and Sass
- JavaScript
- Git and GitHub

## What I learnt

Building this portfolio helped me practise responsive layouts, organise styles with Sass and create consistent navigation across multiple pages. I’ve continued updating it as I complete projects and develop new skills.

## Running locally

Download or clone this repository and open `index.html` in your browser. You can also use a local development server, such as Live Server in VS Code.

## Project status

This portfolio is an ongoing project. I’ll continue adding completed work, updating coding examples and improving the site as my training progresses.
